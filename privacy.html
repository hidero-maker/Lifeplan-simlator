ライフプランシミュレーター ・ 2026年10月27日 制定

このアプリについて

ライフプランシミュレーターは、家族の収支と資産の見通しを計算するための個人用ウェブアプリです。運営者の家族が利用することを目的としています。

扱う情報

  • 利用者が入力した収入・生活費・資産残高などの家計の情報
  • Googleドライブに接続した場合の、Googleアカウントのアクセス許可

情報の保存場所

入力した情報は、利用者のブラウザと、利用者自身のGoogleドライブに保存されます。運営者のサーバーに送信・保存することはありません。

Googleのデータの利用

このアプリが利用するGoogleドライブの権限は、アプリで作成したファイルと、利用者がアプリで選んだファイルだけを扱う権限(drive.file)です。それ以外のファイルを読み書きすることはありません。取得した情報は、計算結果の表示と、利用者が指定した家族とのデータ共有にのみ使います。第三者への提供、広告への利用、販売は行いません。Google APIから受け取った情報の利用は、Google API Services User Data Policy(限定的使用の要件を含む)に従います。

情報の削除

ブラウザに保存された情報は、ブラウザのサイトデータを削除すると消えます。Googleドライブに保存された情報は、利用者がGoogleドライブの「ライフプラン」フォルダのファイルを削除すると消えます。アプリへのアクセス許可は、Googleアカウントの設定からいつでも取り消せます。
